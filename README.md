## Hikaro — Cybersecurity Red Team & Developer

I'm a **cybersecurity red team enthusiast** focused on offensive security, reverse engineering, and system internals. I think like an attacker to understand how to build better defenses. On the side I write Python tools and CLIs that I actually use.

📸 Instagram: [@Hikaro.yy](https://instagram.com/hikaro.yy) · 🐙 GitHub: [1cz1](https://github.com/1cz1)

### 🔐 What I work on

- **Red Teaming & Offensive Security** — attack simulation, recon, exploitation
- **Reverse Engineering & Debugging** — IDA, Ghidra, x64dbg, Cheat Engine, ReClass
- **Memory Hacking & Game Internals** — process memory, pointers, offsets
- **Low-level tool development** — C, C++, C# for system-level work
- **Anti-cheat research** — EAC, BattlEye, VAC concepts and bypass techniques
- **Python tooling** — CLI tools, automation, PyPI packages
